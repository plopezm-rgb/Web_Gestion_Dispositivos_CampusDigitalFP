# Aplicación para la gestión de Dispositivos y Periféricos - Campus Digital FP

Proyecto enfocado en la gestión y administración de dispositivos y periféricos dentro del entorno educativo de Campus Digital FP.

La aplicación fue diseñada para facilitar el control del inventario, la asignación de dispositivos, la gestión de incidencias y el seguimiento de los equipos utilizados por alumnado y profesorado. :contentReference[oaicite:0]{index=0}

---

## Tecnologías utilizadas

- HTML5
- CSS3
- PHP
- JavaScript
- SQL
- MySQL
- GitHub
- Visual Studio Code

La elección de PHP, HTML y CSS se realizó por su facilidad de integración con bases de datos, estructura web y rapidez de desarrollo para aplicaciones dinámicas. 

---

## Funcionalidades

- Inicio de sesión y autenticación de usuarios
- Gestión de dispositivos y periféricos
- Operaciones CRUD
- Asignación de dispositivos a alumnos y aulas
- Registro y consulta de incidencias
- Actualización del estado de incidencias
- Generación de reportes
- Gestión de inventario tecnológico

Los diferentes casos de uso se organizaron mediante roles de administrador y alumno para controlar el acceso y las funcionalidades disponibles.

---

## Roles de usuario

### Administrador / Profesor

- Gestionar dispositivos
- Registrar incidencias
- Actualizar información
- Generar reportes
- Gestionar usuarios

### Alumno

- Consultar dispositivos asignados
- Registrar incidencias
- Acceder a la información de sus dispositivos

---

## Objetivo del proyecto

Desarrollar una aplicación web funcional que permitiera gestionar de manera organizada los dispositivos tecnológicos del centro, facilitando el control del inventario y el seguimiento de incidencias.
